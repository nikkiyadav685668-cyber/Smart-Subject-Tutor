# Knowlix

### Learn Smarter. Grow Further.

**Knowlix** is a modern AI-powered knowledge platform designed for students, especially engineering students.

It helps students understand subjects, learn new concepts, and get personalized academic support using Artificial Intelligence and Retrieval-Augmented Generation (RAG).

## Features

- 📚 Multiple Engineering Subjects
- 🤖 AI-Powered Subject Tutor
- 📄 Upload and Ask Questions from PDF Notes
- 🔍 RAG-Based Answer Retrieval
- 📖 Answers with PDF Page References
- 🧠 Personalized Learning Support
- 💻 Interactive Learning Experience

## Technology Stack

- Python
- Streamlit
- Retrieval-Augmented Generation (RAG)
- ChromaDB
- Sentence Transformers
- Gemini / OpenAI / Claude API

## Project Goal

To make learning easier, smarter, and more accessible by combining educational resources with AI technology.
